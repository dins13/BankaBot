# BankaBot + Mini App

Telegram-бот для учёта финансов и Telegram Mini App с тем же функционалом.
Оба используют одну базу `finance.db`.

## Возможности

- Добавление расходов и доходов (сумма, категория, комментарий, дата).
- Удаление операций.
- Распределение по существующим категориям (из истории + категории по умолчанию).
- История операций с фильтрами по периоду, типу и категории.
- Аналитика:
  - доходы, расходы, баланс;
  - средний расход в день;
  - распределение по категориям (кольцевая диаграмма и легенда);
  - динамика по времени (дни / недели / месяцы);
  - топ категорий расходов.

## Структура

```
bot.py                 запуск бота + встроенного веб-сервера Mini App
handlers.py            команды бота, /app и кнопка Mini App
services.py            парсинг, периоды, отчёты
database.py            SQLite-слой (общий для бота и Mini App)
webapp/
  api.py               FastAPI: REST API + раздача статики
  auth.py              проверка подписи Telegram initData
  static/
    index.html
    styles.css
    app.js
finance.db             база данных (создаётся автоматически)
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Одной командой поднимаются и бот, и веб-сервер Mini App (порт 8000 по умолчанию):

```bash
python bot.py
```

Веб-сервер стартует автоматически вместе с ботом. Отключить его можно
переменной `WEBAPP_EMBED=0` (например, если фронтенд хостится отдельно),
адрес и порт задаются через `WEBAPP_HOST` и `WEBAPP_PORT`.

## Локальный запуск Mini App отдельно

Для отладки только веб-части без бота:

```bash
WEBAPP_DEV_MODE=1 uvicorn webapp.api:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000 — в dev-режиме запросы авторизуются под
пользователем `1` (или `?dev_user=123`, `X-Dev-User: 123`).
Можно посмотреть и изменить те же операции, что и в боте.

В dev-режиме удобно наполнить базу через API:

```bash
curl -X POST http://localhost:8000/api/operations \
  -H 'Content-Type: application/json' \
  -d '{"type":"expense","amount":450,"category":"еда","comment":"обед"}'
```

## Подключение к Telegram

Telegram открывает Mini App только по публичному HTTPS-адресу.

### Быстрый способ: бот + туннель одной командой

```bash
./scripts/run_with_tunnel.sh
```

Скрипт поднимает SSH-туннель через `localhost.run`, получает публичный
HTTPS-адрес и запускает `bot.py` с `WEBAPP_URL`, после чего кнопка меню
«Финансы» обновляется автоматически.

> У бесплатных quick-туннелей `localhost.run` домен может периодически
> меняться. Если Mini App внезапно перестал открываться («no tunnel»),
> остановите скрипт (Ctrl+C) и запустите его снова — бот подхватит новый
> адрес. Для постоянного домена зарегистрируйте ключ на localhost.run или
> используйте `ngrok`/именованный туннель `cloudflared`.

### Вручную

```bash
# вариант 1: cloudflared
cloudflared tunnel --url http://localhost:8000

# вариант 2: ngrok
ngrok http 8000
```

Затем запустите бота с публичным адресом — веб-сервер поднимется сам:

```bash
export WEBAPP_URL="https://<ваш-адрес>"
export BOT_TOKEN="<токен-бота>"

python bot.py
```

> ⚠️ **Не используйте туннель VS Code (`*.devtunnels.ms`) для Mini App.**
> Он отдаёт браузеру (и Telegram WebView) страницу-предупреждение
> «You are about to connect to a developer tunnel… Continue». Telegram её
> не проходит, и приложение выглядит как «no tunnel» / не открывается.
> Используйте `cloudflared`, `ngrok` или `localhost.run`.

- При старте бот поднимает веб-сервер Mini App на `WEBAPP_HOST:WEBAPP_PORT`
  (по умолчанию `0.0.0.0:8000`) и устанавливает кнопку меню «Финансы».
- Команда `/app` пришлёт кнопку запуска Mini App.
- Авторизация в API выполняется по подписи `initData`, токен бота должен
  совпадать у бота и Mini App (`BOT_TOKEN`).

## Переменные окружения

| Переменная        | Назначение                                             |
|-------------------|--------------------------------------------------------|
| `BOT_TOKEN`       | Токен Telegram-бота (бот и проверка initData)          |
| `WEBAPP_URL`      | Публичный HTTPS-адрес Mini App для кнопок в боте       |
| `WEBAPP_DEV_MODE` | `1` — разрешить доступ без Telegram (только локально)  |
| `WEBAPP_EMBED`    | `1` (по умолчанию) — поднимать веб-сервер вместе с ботом |
| `WEBAPP_HOST`     | Адрес встроенного веб-сервера (по умолчанию `0.0.0.0`) |
| `WEBAPP_PORT`     | Порт встроенного веб-сервера (по умолчанию `8000`)     |
| `HOST`, `PORT`    | Адрес и порт при запуске `python -m webapp.api`        |

## API

| Метод  | Путь                    | Описание                                  |
|--------|-------------------------|-------------------------------------------|
| GET    | `/api/me`               | Пользователь и общий баланс               |
| GET    | `/api/categories`       | Существующие категории по типам           |
| GET    | `/api/operations`       | История с фильтрами и итогами             |
| POST   | `/api/operations`       | Добавить операцию                         |
| DELETE | `/api/operations/{id}`  | Удалить операцию                          |
| GET    | `/api/stats`            | Сводка, категории, динамика по периодам   |

Параметры периода: `start` и `end` в формате `YYYY-MM-DD` (включительно).
Для динамики — `bucket=day|week|month` (по умолчанию подбирается автоматически).

## О проекте

Telegram-бот для учёта личных финансов с мини-приложением и ИИ-помощником. Сделан для тех, кто хочет копить на цели, но не хочет разбираться в финансах: написал `250 — кофе`, и расход записан.

Бот показывает аналитику за выбранный период (по категориям и в динамике): текстом в чате и графиками в мини-приложении. Данные можно выгрузить в Excel. По кнопке после аналитики ИИ-помощник даёт совет, как сэкономить или накопить.
